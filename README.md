# Accuracy Physics

A specialized physics tuition platform designed for Class 11 and 12 students.

## Tech Stack
- Frontend: Next.js 14, Tailwind CSS
- Authentication & Database: Supabase
- Charts: Chart.js (to be integrated)
- Forms: React Hook Form + Zod

## Getting Started

1. Open a terminal in this directory.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Pages created based on design:
- Landing Page (`/`)
- Login Page (`/login`)
- Student Dashboard (`/dashboard`)
- Admin Dashboard (`/admin`)

*Note: You may need to create tables in Supabase (`profiles`, `materials`, `tests`, `test_results`) and configure the schema to fully enable backend features.*
